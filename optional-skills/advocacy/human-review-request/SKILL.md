# Human Review Request — Burgess Principle

Help users draft calm, respectful letters to institutions asking one simple question:

> "Was a human member of the team able to personally review the specific facts of my situation?"

## When to Use

- User says they received an automated decision (fine, penalty, bill, denial, ban, removal)
- User feels they were treated as a "data point" rather than an individual
- User wants to challenge or question an institutional decision
- User asks for help writing to a council, utility company, bank, court, platform, employer, or government body
- User mentions enforcement agents, bailiffs, debt collectors, or automated penalties

## Procedure

1. **Listen** — Ask the user to describe their situation. What happened? Which institution? What was the decision?
2. **Identify** — Determine the core issue: was individual human attention given to their specific case?
3. **Draft** — Write a letter in the Burgess Principle tone: calm, polite, firm, respectful. No aggression, no legal threats (unless the user explicitly asks for legal language).
4. **Structure** the letter:
   - Opening: polite introduction, reference number or account details
   - The Question: "Was a human member of your team able to personally review the specific facts of my situation before this decision was made?"
   - Context: brief, factual summary of the user's specific circumstances
   - Request: ask for written confirmation of whether individual human review took place
   - Close: respectful sign-off with a reasonable response deadline (14–28 days)
5. **Adapt** — If the user mentions disability, sensory needs, or communication preferences, include a reference to reasonable adjustments (Equality Act 2010 in the UK, or local equivalent).

## Tone Guidelines

- **Calm** — Never angry, never threatening, never condescending
- **Respectful** — Assume good faith. The person reading the letter is also human
- **Firm** — The question is clear and requires a clear answer
- **Specific** — Always reference the user's individual facts, never generic complaints
- **Empowering** — The user is asking a reasonable question, not begging for help

## Domains

This skill works across all domains:

| Domain | Example |
|--------|---------|
| Enforcement | Warrants, fines, penalties, bailiff visits |
| Billing | Utility bills, disputed charges, debt collection |
| Credit | Credit file entries, defaults, scoring decisions |
| Benefits | Universal Credit, disability assessments, housing |
| Platforms | Account bans, content removal, demonetisation |
| Medical | Algorithmic diagnosis, hearing aid fitting, treatment decisions |
| Employment | Automated screening, redundancy selection, performance scoring |

## Verification

- The letter contains the Burgess Principle question (or a clear equivalent)
- The letter references the user's specific situation, not generic complaints
- The tone is calm, respectful, and firm throughout
- A response deadline is included
- If disability/accessibility is relevant, reasonable adjustments are mentioned
